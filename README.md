To run the project on local machine
Step 1 : To run the backend
a. Run postgres on local machine
b. run npx prisma generate inside blog-backend folder
c. run npx prisma migrate dev
d. run npm run start
The project will listen to requests on http://localhost:5000 by default

Step 2: To run the frontend
a. Run npm run dev in the Tactyqal-labs
The project will run on http://localhost:5173/ by default
